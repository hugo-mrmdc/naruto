COPIE POUR DECOMPILATION UNIQUEMENT — NE PAS LANCER EN JEU

1. Extraire rp_atg_naruto2.bsp (garder ce nom) dans un dossier distinct.
2. Decompiler avec la version recente de BSPSource vers un VMF.
3. Le BSP d'origine comporte 9021 prop_static et 541 modeles distincts. Cette copie les inscrit dans la liste des entites pour que BSPSource les reporte dans le VMF. Le game lump des props est masque dans cette copie pour eviter des doublons.
4. Les modeles .mdl et leurs textures ne sont PAS inclus dans le BSP. Installer les addons GMod requis dans les chemins utilises par Hammer. Voir modeles_requis.txt.
5. La protection de l'ancien BSP a detruit les classes/positions de nombreuses autres entites, y compris des portes et TP. Les brush entities non reliees ne peuvent pas etre replacees automatiquement. Ce VMF n'est PAS une reconstruction fidele ou directement recompilable de toute la map.
6. Pour jouer, utiliser le BSP de jeu separe, pas ce fichier de decompilation.

Version corrigee : game lump sprp vide mais valide pour eviter une EOFException dans BSPSource 1.4.8.
